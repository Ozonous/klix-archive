# KLIX Archive

Hello! Welcome to the KLIX Archive.

This archive is here to preserve what is left of the KLIX Roblox revival, which lasted from around Late January 2025 to late February 2025.

This archive has been made to be clean and contain as much KLIX stuff as I currently know/remember.

It contains:
- Client backups
- RCCService backups
- Site related stuff
- Miscellaneous items
- Archived links

---

# Folders

## 1. Clients

Contains various KLIX clients, mainly from 2015-2017.

Most of these seem broken and I have not really been able to get them working properly.

I do remember there being a 2012 client in the works, but I believe it may be lost to time.

---

## 2. RCCService

Contains two RCCService related backups.

I have not really tested these much because I honestly forgot how RCCService was setup back then.

---

## 3. Site

Does **NOT** contain the full KLIX website source code.

It mainly contains ZIPs from old ChatGPT chats that were used while making the KLIX site.

The KLIX website was AI generated.

Not much here has really been tested properly yet. If site source code does eventually pop up, it will be added to the folder.

---

## 4. Web (links)

Contains links to webpages and a Wayback Machine snapshot (maybe) related to KLIX.

One of them seems to maybe be some sort of Squared rehost, but I do not know if it was from before, during or after KLIX.

---

## 5. Misc

Contains miscellaneous KLIX related stuff.

---

## 6. Photos

Photos of the KLIX website and other related things.

---

# Current State

At the moment, the original KLIX website source code seems to be mostly lost.

There **WAS** a source code leak at one point, but it was uploaded to MediaFire and the file later got deleted.

As of now, it has not been recovered.

Most surviving KLIX things currently seem to be:
- Clients
- RCCService
- Partial site stuff
- Old links
- Screenshots
